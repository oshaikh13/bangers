# QA Type: Predictive Struggles

Generate questions about where the user will get stuck, what they will look up,
what they will ask for help with, or what will slow them down soon. Questions
can be generic or hook into a struggle-prone artifact, thread, or task visible
in `context_events`.

Prefer concrete but simple questions:

- "Where will the user get stuck in the next hour?"
- "What will the user look up next?"
- "What help will the user ask for next?"

Use future logs for the answer and avoid over-interpreting a single noisy
screen or audio record.
