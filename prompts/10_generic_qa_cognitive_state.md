# QA Type: Cognitive State

Generate questions about the user's mode of thinking: exploring, deciding,
debugging, writing, comparing, planning, avoiding, or executing. Questions can
be generic or reference a specific decision, exploration, or artifact visible
in `context_events`.

Good questions ask what the user is trying to understand, what mental mode they
will enter next, or what uncertainty will resolve soon. Avoid abstract labels
unless the answer ties them to concrete behavior.

Use future logs when predicting a shift; use history only for current-state
synthesis.
