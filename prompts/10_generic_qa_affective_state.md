# QA Type: Affective State

Generate questions about the user's likely emotional state: frustration,
relief, fatigue, urgency, confidence, hesitation, or engagement. Questions can
be generic or reference a specific situation, artifact, or thread visible in
`context_events`.

Keep questions simple and observable. Do not infer deep emotion from one noisy
audio line. Use repeated behavior, language, switching, retries, or future
follow-through as evidence.

Prefer near-future questions such as "How will the user feel about this in the
next hour?" when future evidence is available.
