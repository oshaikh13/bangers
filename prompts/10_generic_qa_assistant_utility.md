# QA Type: Assistant Utility

Generate questions about what an assistant could usefully know or surface for
the user soon. Questions can be generic or reference a specific situation,
artifact, or upcoming need visible in `context_events`.

Focus on future-predictive utility: what context the user will search for,
what artifact would save time, what reminder would matter, or what help mode
the user will accept.

Answers should name the useful surface or help style, and why it fits the
user's next behavior.
