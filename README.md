# Bangers Discovery Data Pipeline

This repo turns passive PowerNap-style activity logs into a final set of execution questions for proactive assistant suggestions.

The pipeline has two parts:

1. Build indexed activity data in `logs-indexed/`.
2. Run the four discovery stages into `discovery_<provider>_<interval>/`.

## Prerequisites

- Python 3.11+
- `uv`
- Either `codex` or `claude` on your `PATH`
- Source logs, by default at `../powernap/logs`

Install dependencies:

```bash
uv sync
```

## 1. Build Indexed Logs

Run all indexing stages:

```bash
./scripts/index_all.sh
```

This creates or updates:

```text
staging/
  screen.jsonl
  calendar.jsonl
  email.jsonl
  notifications.jsonl
  filesys.jsonl
  audio.jsonl

logs-indexed/
  screen/<date>.jsonl
  calendar/<date>.jsonl
  ...
  screenshots/
```

Useful environment overrides:

```bash
POWERNAP_LOGS_DIR=/path/to/powernap/logs
STAGING_DIR=/path/to/staging
LOGS_INDEXED_DIR=/path/to/logs-indexed
SCREEN_SCREENSHOTS_DIR=/path/to/labeled_screenshots
```

## 2. Create Interval Records

Discovery runs over interval rows, not directly over the whole logs folder.

```bash
uv run scripts/record_intervals.py 15
```

This writes:

```text
data/log_intervals_15m.jsonl
```

Use another interval size if needed:

```bash
uv run scripts/record_intervals.py 30
```

## 3. Run Discovery

The default output directory is:

```text
discovery_<provider>_<interval>m/
```

For example, with Codex and 15-minute intervals:

```text
discovery_codex_15m/
  01_goals/
  02_combined/
  03_bangers/
  04_questions/
```

Run the stages in order (this will run on the first ten 15 min interval):

```bash
uv run scripts/run_discovery_goals.py --provider codex --interval-indexes 0-10 --jobs 2
uv run scripts/run_discovery_combine.py --provider codex
uv run scripts/run_discovery_bangers.py --provider codex --jobs 2
uv run scripts/run_discovery_questions.py --provider codex --jobs 2
```

Or use Claude:

```bash
uv run scripts/run_discovery_goals.py --provider claude --interval-indexes 0-10 --jobs 2
uv run scripts/run_discovery_combine.py --provider claude --force
uv run scripts/run_discovery_bangers.py --provider claude --jobs 2
uv run scripts/run_discovery_questions.py --provider claude --jobs 2
```

## Stage Outputs

### `01_goals`

Generated by:

```bash
uv run scripts/run_discovery_goals.py
```

Writes one file per selected interval:

```text
discovery_codex_15m/01_goals/goal_<interval_index>.json
```

Select intervals with:

```bash
--interval-indexes 0,3,10-12
--start 50 --limit 25
```

### `02_combined`

Generated by:

```bash
uv run scripts/run_discovery_combine.py
```

Reads `01_goals/goal_*.json` and writes:

```text
discovery_codex_15m/02_combined/combined.json
```

### `03_bangers`

Generated by:

```bash
uv run scripts/run_discovery_bangers.py
```

Reads `02_combined/combined.json` and writes:

```text
discovery_codex_15m/03_bangers/banger_<combined_index>.json
```

Run a subset with:

```bash
--combined-indexes 0,4,8-10
```

### `04_questions`

Generated by:

```bash
uv run scripts/run_discovery_questions.py
```

Reads `03_bangers/banger_*.json` and writes:

```text
discovery_codex_15m/04_questions/question_<combined>_<goal>_<opportunity>.json
discovery_codex_15m/04_questions/final_questions.json
```

`final_questions.json` is the final consolidated artifact.

## Common Options

Use a different output root:

```bash
--discovery-dir /path/to/discovery_run
```

Use a different interval size:

```bash
--interval-minutes 30
```

Preview a stage without invoking the model:

```bash
--dry-run
```

Print the full rendered prompt during a dry run:

```bash
--dry-run --print-prompt
```

Overwrite existing outputs:

```bash
--force
```

Continue after per-item failures:

```bash
--continue-on-error
```

## Quick Smoke Test

After indexing and interval creation, run one interval through the first stage:

```bash
uv run scripts/run_discovery_goals.py --provider codex --interval-indexes 0 --dry-run
```

Then run a real small pass:

```bash
uv run scripts/run_discovery_goals.py --provider codex --interval-indexes 0
uv run scripts/run_discovery_combine.py --provider codex --force
uv run scripts/run_discovery_bangers.py --provider codex --combined-indexes 0
uv run scripts/run_discovery_questions.py --provider codex --combined-indexes 0
```
